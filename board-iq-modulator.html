IQ Modulator

Portable IQ transmitter board, 373 MHz to 1.6 GHz, for teaching communication systems

The IQ modulator board designed and developed in WEL up-converts a complex baseband signal to a passband IF or RF signal in the few-GHz range.

Product developers: Manu T. S., Saurabh A., Maheshwar M.

Used in: EE 340: Communications Lab

Features

  • Up-converts a complex baseband signal to a passband IF (intermediate frequency) or RF (radio frequency) signal in the few-GHz range
  • An IQ demodulator — a commercial RTL-SDR dongle — down-converts the passband RF or IF signal back to complex baseband. It connects to the USB port of a computer and is processed with GNU Radio
  • The open-source GNU Radio environment is used to build the communication blocks for transmission and reception on the computer

Need this board for a project?

Development boards and the modules that go with them can be borrowed from WEL for a set period. Course kits are issued through the teaching lab staff.
