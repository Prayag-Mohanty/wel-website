WEL Inventory

The component stock portal: search what the lab holds, build a cart and submit a request as a project team.

Component stock

What the lab holds, and how to ask for it

WEL Inventory is the lab's component stock system. The full listing is on this page — search it, build a request list and send it to the lab, without signing in.

The same stock is also served by the WEL Inventory portal, which adds team accounts, a tracked request queue and automatic stock updates on approval. Both read the same component spreadsheet.

About the components Ask the lab
The portal is not online yet. WEL Inventory is a Flask application that lives with this website's source in inventory-app/. It needs a host that can run Python — the lab server, or a free service such as PythonAnywhere. Once it is running, put its address in SITE["inventory_app"] in _src/build.py and every link on this site will point at it. Setup steps are in inventory-app/DEPLOY.md.

    For project teams

    How to raise a component request

    Two ways, depending on whether the portal is running.

    1. Find the parts

    Search the listing above by model number, description, type or where it is kept, and filter by availability.

    2. Build your list

    Set a quantity for each part and add it. The list stays in your browser, so you can come back to it later.

    3. Send it

    Add your team name, members and what it is for, then email the list to the lab or copy it as text.

    4. Collect

    Lab staff check the stock and confirm. Nothing is reserved until they reply.

    Through the portal instead. When the WEL Inventory portal is running, teams register once with one @iitb.ac.in address, submit the same cart through it, and track the status under My Requests. Approval there decrements stock automatically, and a team can have one pending request at a time. The listing above and the portal read the same component spreadsheet.
    For lab staff

    What the admin side does

    Review requests

    Pending, approved and rejected requests, each showing the team name and every member with their roll number. Approving issues the parts and decrements stock; stock is checked before the request goes through.

    Manage stock

    Edit quantities in place, and see a low-stock list of everything at two units or fewer so reordering happens before a course needs the part.

    Bulk import

    Import the component list from an Excel workbook or a Google Sheet link. Columns map to type, model number, description, link, location and quantity.

    Something missing from the stock?

    If a part you need is not listed, or the quantity looks wrong, tell the lab staff rather than assuming it is unavailable — stock is updated as parts arrive.
